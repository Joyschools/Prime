Prime Institutional Upgrade v4 — User Management Transformation

This pass turns User Management into a working institutional people/account centre.

Highlights:
- Admin can create ICT and all supported account types.
- ICT can create ordinary non-Admin/non-ICT accounts.
- Role, department, title and authority remain separate.
- College/University modes automatically provision Communications and Computer Studies departments when absent.
- Temporary passwords are stored only as hashes; users can change them later and Admin can reset an account with a new password.
- Searchable directory with edit and archive/deactivate controls.
- Optional learner accountability details: DOB, gender, ID/reference, address, emergency contacts, blood group, health notes and notes.
- Parent accounts can be linked to a learner through student_guardians.
- Existing student health/guardian fields remain intact.
- Historical account records are preserved when access is archived.
- No new Staff login role was introduced; institutional titles such as HOD, Deputy and Dean are positions layered on the functional portal role to keep permissions predictable.
